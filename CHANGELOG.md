# Endringslogg

## 1.0.0

Første versjon.

- Navidrome for musikk i nettleseren og i Subsonic-apper på mobil og PC.
- Lidarr følger artister og henter album selv, i kvaliteten du velger (Standard eller tapsfri).
- SABnzbd for Usenet, og valgfritt qBittorrent bak VPN.
- Veiviser som finner Plex-stack på maskinen og kan bruke nedlasterne derfra.
- Autooppsett: administrator i Navidrome, rotmappe, kvalitet og nedlastingsklienter i Lidarr,
  server og kategori i SABnzbd, kategorier i qBittorrent og NZBGet, Lidarr koblet til Prowlarr,
  dashboard med tall.
- Nettverksdeling (NFS/SMB), rolig modus og kjøling.
- Pakker for Linux, macOS og Windows.
